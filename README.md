# Beachball LAN

Простая сетевая игра для двух игроков в стиле Beachball. Игроки — два шара, которые отбивают пляжный мяч через сетку. Если мяч приземляется на твоей стороне, соперник получает очко. Матч идет до 13 очков.

## Управление

- `A` / `D` или стрелки влево/вправо — движение по своей половине поля.
- `W` или стрелка вверх — прыжок, если игрок стоит на земле.
- `S` или стрелка вниз — быстрое падение вниз в воздухе.
- Быстрое двойное нажатие любой клавиши движения (`A`, `D`, `W`, `S` или стрелки) — dash в направлении этой клавиши.

## Запуск через Radmin VPN

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Оба игрока подключаются к одной сети Radmin VPN.
3. Игрок-хост запускает сервер:

   ```bash
   npm start
   ```

4. Хост смотрит Radmin VPN IPv4-адрес своего ПК и сообщает второму игроку адрес вида:

   ```text
   http://RADMIN-IP:3000
   ```

5. Оба игрока открывают страницу в браузере, вводят одинаковую комнату и нажимают **Играть**. Для локального теста можно открыть две вкладки на `http://localhost:3000`.

## Сетевой принцип

Сервер на Node.js является авторитетным: он считает физику, счет, столкновения, dash и победу до 13 очков. Клиенты отправляют только ввод клавиш по WebSocket. Благодаря Radmin VPN второй компьютер видит сервер хоста как LAN-адрес.
